# AegisLife Insurance Analytics

End-to-End Insurance Analytics Project using Python, SQL, and Power BI covering Data Cleaning, EDA, Hypothesis Testing, Business Insights, and Interactive Dashboards.

---

## Project Overview

AegisLife Insurance Analytics is an end-to-end data analytics project focused on analyzing insurance operations including customer behavior, claims performance, fraud detection, risk segmentation, and agent productivity.

The project follows a complete analytics workflow:

- Data Cleaning and preprocessing using Python
- Exploratory Data Analysis (EDA)
- SQL-based KPI and business analysis
- Statistical Hypothesis Testing
- Power BI Dashboard development
- Business insights and recommendations

## Key KPIs

- Total Customers: 1,648  
- Total Policies: 2,828  
- Total Claims: 1,406  
- Total Claim Amount: ₹355.62M  
- Approval Rate: 35.85%  
- Fraud Rate: 49%  
- Loss Ratio: 4.71  
- Policy Lapse Rate: 32%

---

## Key Business Insights

- Fraud rate is significantly high (~49%), indicating need for stronger claim verification systems
- Property insurance has the highest loss ratio among all products
- Around 69% of customers fall into the medium risk category
- Policy lapse rate is 32%, indicating customer retention issues
- Health insurance contributes the highest total claim amount

---

## Analysis Performed

- Data cleaning and preprocessing using Python (Pandas)
- Exploratory Data Analysis (EDA) for trend identification
- SQL queries for KPI extraction and business analysis
- Hypothesis testing (T-test, ANOVA, Chi-square, correlation analysis)
- Customer risk segmentation analysis
- Agent performance evaluation and fraud detection insights

---

## Business Recommendations

- Strengthen fraud detection system using predictive analytics
- Improve customer retention strategies to reduce policy lapse rate
- Focus on high-risk customer monitoring and engagement
- Optimize underwriting policies for high-loss segments like property insurance
